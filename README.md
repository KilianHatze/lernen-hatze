# Lernen Hatze – Web-Version

Lern-App für Fachinformatiker/-innen Systemintegration: Lernübersichten, Formelsammlung, Eselsbrücken und Prüfungstrainer.

- **Im Browser öffnen:** https://kilianhatze.github.io/lernen-hatze/
- **Windows-App herunterladen:** [LernenHatze-Windows.zip](https://github.com/KilianHatze/lernen-hatze/releases/latest/download/LernenHatze-Windows.zip) – entpacken und `LernenHatze.exe` starten (Anleitung in `LIESMICH.txt`).

Dieses Repository enthält nur die fertig gebaute Web-Version.

Privates Lernprojekt, keine offizielle App der IHK oder eines Bildungsträgers. Die Beispielfirmen sind frei erfunden.
